## Como funciona

A IA escreve o código com você, e **explica tudo pelo caminho**: o que vai fazer, como vai fazer e por que escolheu aquele jeito. Você planeja, testa, pergunta e aprende. No fim, o projeto é seu, e você sabe explicar cada pedacinho dele.

Todo projeto segue o mesmo caminho:

1. **Escolher a stack** e preparar o computador.
2. **Documentar** a ideia: o que ela faz, as telas, os dados e como a IA vai ajudar.
3. **Criar o repositório** no GitHub.
4. **Dividir em partes** e construir uma de cada vez, com a professora explicando cada linha.
5. **Revisar, escrever o README e publicar** no GitHub Pages.

## Dicas para aproveitar

- Siga a ordem da trilha: cada projeto é um pouquinho mais desafiador que o anterior.
- Leia a ideia inteira antes de começar.
- Pergunte sempre o porquê. A professora não se cansa!
