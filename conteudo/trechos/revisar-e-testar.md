### Etapa — Revisar e testar

**Objetivo:** encontrar erros e pontos de melhoria antes de mostrar o projeto para o mundo.

1. **Passe pelos requisitos.** Volte à seção Requisitos desta página e confira, um por um, se o projeto faz tudo o que é obrigatório.
2. **Teste em telas diferentes.** No navegador, aperte F12 para abrir o *DevTools* (as ferramentas de desenvolvedor) e clique no ícone de celular e tablet para ver o site em larguras menores.
3. **Olhe o console.** Ainda no DevTools, abra a aba **Console**. Mensagens em vermelho são erros, e nenhuma deve aparecer.
4. **Valide o HTML** em validator.w3.org, na opção **Validate by Direct Input**, colando o conteúdo do seu `index.html`. O validador aponta tags fechadas errado, atributos faltando e outros deslizes.
5. **Peça uma revisão para a professora:**

```prompt
Terminei o projeto "{{titulo}}". Esta é a documentação:

[COLE AQUI O SEU docs/projeto.md]

E este é o código de cada arquivo:

[COLE AQUI O CÓDIGO DE CADA ARQUIVO, COM O NOME DE CADA UM]

Revise o projeto como uma professora corrigindo um trabalho: aponte erros, problemas de acessibilidade e de organização, e o que pode melhorar. Para cada ponto, explique o problema, por que ele importa e como corrigir. Comece pelos mais importantes.
```

Corrija um ponto por vez, testando depois de cada correção. Para cada correção relevante, faça um commit com uma mensagem que diga o que foi corrigido.
